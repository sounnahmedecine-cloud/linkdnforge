# 🚀 LinkedInForge Capture — Extension Chrome (MVP)

Transformez n'importe quelle page web, article, vidéo ou extrait surligné en brouillon LinkedIn percutant en 1 clic.

---

## 📥 Comment installer l'extension dans Google Chrome (en 30 secondes) :

1. Ouvrez **Google Chrome** et rendez-vous sur la page des extensions en tapant :
   ```
   chrome://extensions
   ```
2. Activez le **« Mode développeur »** (en haut à droite de l'écran).
3. Cliquez sur le bouton **« Charger l'extension non empaquetée »** (en haut à gauche).
4. Sélectionnez le dossier :
   ```
   d:\MES PROJETS\linkdnforge\chrome-extension
   ```
5. ✨ **C'est tout !** L'icône de **LinkedInForge Capture** apparaît dans votre barre d'extensions Chrome (vous pouvez l'épingler avec l'icône de punaise).

---

## 🎯 Fonctionnalités incluses dans le MVP :

### 1. Capture en 1 clic depuis le Popup :
- Cliquez sur l'icône de l'extension sur n'importe quel site ou article.
- L'extension détecte automatiquement le titre et l'URL.
- Choisissez votre tonalité (*👑 Autorité, 📖 Storytelling, 💡 Éducatif, ⚡ Direct, 💬 Discussion*).
- Cliquez sur **« ⚡ Forger un post (IA) »**.
- Obtenez votre brouillon + **3 variantes de Hooks**. En cliquant sur un Hook, il remplace automatiquement la 1ère phrase du post !
- Cliquez sur **« Copier le post »** pour le coller directement sur LinkedIn.

### 2. Clic droit sur du texte surligné :
- Surlignez n'importe quel passage marquant sur un article ou une page.
- Faites **Clic droit → « ⚡ Forger un post avec LinkedInForge »**.
- L'Atelier s'ouvre instantanément avec le contenu sélectionné prêt à être forgé !

### 3. Bouton « Ouvrir dans l'Atelier LinkedInForge » :
- Permet de basculer à tout moment vers le Studio complet sur `linkedinforge.fr` avec les données préremplies.
